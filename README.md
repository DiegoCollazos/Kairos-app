# Kairós · Interfaz web

Interfaz del formulador de Kairós, publicada con GitHub Pages.

Este repositorio contiene **solo la página** (pantallas, estilos y logo). Los datos de cada organización viven en repositorios privados `kairos-datos-<org>`, y solo se accede a ellos con un token personal de GitHub.
